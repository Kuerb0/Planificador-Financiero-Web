# Planificador financiero (web)

Planificador interactivo hecho con Streamlit: hipoteca, cartera con Monte Carlo, comparador, ahorro, asignación de activos y test de riesgo.

- **Usarlo:** [planificador-financiero en Streamlit Cloud](https://planificador-financiero-ebptettnct3wpthqbtssct.streamlit.app/). Las apps de Streamlit se duermen; el [portal](https://kuerb0.github.io/portal/) siempre está encendido.
- **En local:** `pip install -r py/requirements.txt` y `streamlit run py/app_planificador.py`.
- Los datos de mercado están en [`csv/`](csv/).

Es una herramienta educativa, no asesoramiento financiero.
